# TomatoBird

AI 驱动的大学生本地优先生活管理平台 —— Windows 测试版下载。

> ⚠️ **声明**:这是**未完成的测试版**,仍存在较多 bug,部分功能尚不可用或体验不佳,请谨慎使用。应用数据仅保存在你自己的电脑中,不上传任何信息。

## 下载

下载下方 Assets 中的 `TomatoBird-Setup-0.1.0.exe`(Windows 10/11 64 位),双击安装。
安装时若出现"Windows 已保护你的电脑"提示,点击"更多信息"→"仍要运行"(应用暂无代码签名证书)。

## 当前功能(测试版)

- 课表管理:周视图、拖拽调课、单周停课、冲突检测、今日课程
- 培养方案学分引擎:内置计算机学院弘毅班 2025 方案,支持方案导入
- 教务成绩同步:应用内登录教务系统,一键同步全部学期成绩
- 选课报告与选课模拟:学分缺口一目了然
- 荣誉档案、备忘录、快速账本
- AI 选课建议(需自行申请智谱 API Key)

## 已知问题

- 界面与交互仍在打磨,部分场景可能不便
- 教务登录会话会被服务端定时注销,过期后需重新登录
- AI 解析培养方案 PDF 的准确率有限,导入结果需人工修正

## 隐私

- 所有个人数据仅存储在本地设备,本应用不连接任何自建服务器
- 教务数据通过你本人的登录会话只读获取,凭据仅保存在本机
